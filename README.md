# PyPress
### PyPress Manifesto (v0.1)

> * PyPress is an open-source website platform built with Python.
> * It enables developers and businesses to launch professional websites in minutes while providing a seamless path to evolve those websites into fully customized web applications.
> * PyPress is application-first, plugin-driven, API-ready, and designed for rapid development without sacrificing flexibility.
> * Build a website today. Build your business on it tomorrow.
